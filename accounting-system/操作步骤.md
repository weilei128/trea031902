# 个人收支记账系统 - 操作步骤

## 一、环境要求

- **JDK**: 17 或更高版本
- **Maven**: 3.6 或更高版本
- **浏览器**: Chrome、Firefox、Edge 等现代浏览器

## 二、项目目录结构

```
accounting-system/
├── pom.xml                          # Maven 配置文件
├── src/
│   └── main/
│       ├── java/
│       │   └── com/
│       │       └── accounting/
│       │           ├── AccountingApplication.java    # 启动类
│       │           ├── config/                       # 配置类
│       │           ├── controller/                   # 控制器
│       │           ├── dto/                          # 数据传输对象
│       │           ├── entity/                       # 实体类
│       │           ├── exception/                    # 异常处理
│       │           ├── interceptor/                  # 拦截器
│       │           ├── service/                      # 服务层
│       │           └── util/                         # 工具类
│       └── resources/
│           ├── application.yml      # 应用配置
│           └── static/
│               └── index.html       # H5前端页面
└── data/                            # CSV数据存储目录
    ├── users.csv                    # 用户数据文件
    └── transactions.csv             # 记账数据文件
```

## 三、启动步骤

### 方式一：使用 Maven 命令启动

1. **打开命令行，进入项目目录**
   ```bash
   cd accounting-system
   ```

2. **编译项目**
   ```bash
   mvn clean compile
   ```

3. **运行项目**
   ```bash
   mvn spring-boot:run
   ```

### 方式二：使用 IDE 启动

1. **使用 IntelliJ IDEA 或 Eclipse 打开项目**

2. **等待 Maven 自动下载依赖**

3. **找到启动类** `AccountingApplication.java`

4. **右键运行** `Run 'AccountingApplication'`

### 方式三：打包后运行

1. **打包项目**
   ```bash
   mvn clean package
   ```

2. **运行 jar 包**
   ```bash
   java -jar target/accounting-system-1.0.0.jar
   ```

## 五、功能操作指南

### 1. 用户注册

1. 打开首页 `http://localhost:8080`
2. 点击"注册账号"按钮
3. 填写注册信息：
   - 用户名：手机号（如 13800138000）或邮箱
   - 密码：6-20位字符
   - 确认密码：与密码一致
   - 昵称：可选填
4. 点击"注册"按钮
5. 注册成功后会自动跳转到登录界面

### 2. 用户登录

1. 在登录界面输入用户名和密码
2. 点击"登录"按钮
3. 登录成功后进入主界面

### 3. 添加收支记录

1. 在主界面找到"添加收支记录"卡片
2. 选择类型：收入 或 支出
3. 选择分类（根据类型自动显示对应分类）
4. 输入金额（必须大于0）
5. 填写备注（可选）
6. 点击"保存"按钮

### 4. 查看收支记录

1. 在"收支记录"卡片中查看列表
2. 可使用筛选功能：
   - 按类型筛选（收入/支出）
   - 按分类筛选
   - 按时间范围筛选
3. 点击"筛选"按钮刷新列表
4. 使用"上一页"/"下一页"进行翻页

### 5. 编辑收支记录

1. 在收支记录列表中找到要修改的记录
2. 点击"编辑"按钮
3. 修改相关信息
4. 点击"更新"按钮保存
5. 或点击"取消"放弃修改

### 6. 删除收支记录

1. 在收支记录列表中找到要删除的记录
2. 点击"删除"按钮
3. 在弹出的确认框中点击"确定"

### 7. 查看统计数据

1. 在"收支概览"卡片中查看：
   - 总收入
   - 总支出
   - 结余
2. 可设置时间范围进行筛选
3. 在"分类统计"卡片中查看：
   - 收入分类占比
   - 支出分类占比

### 8. 修改密码

1. 点击页面顶部的"修改密码"按钮
2. 输入旧密码
3. 输入新密码（6-20位）
4. 确认新密码
5. 点击"确认修改"按钮

### 9. 退出登录

点击页面顶部的"退出登录"按钮即可退出。

## 六、数据存储说明

系统使用 CSV 文件存储数据，文件位于项目目录的 `data` 文件夹中：

- **users.csv**: 存储用户信息
- **transactions.csv**: 存储记账记录

数据格式为纯文本，可以用 Excel 或文本编辑器打开查看。

## 七、常见问题

### 1. 端口被占用

如果 8080 端口被占用，可以修改 `application.yml` 中的端口配置：
```yaml
server:
  port: 8081  # 修改为其他端口
```

### 2. 数据文件权限问题

确保程序有权限读写 `data` 目录。如果出现问题，可以：
- 手动创建 `data` 目录
- 检查目录权限

### 3. 登录状态丢失

系统使用 JWT Token 进行身份认证，Token 有效期为 24 小时。如果登录过期，需要重新登录。

## 八、API 测试示例

### 使用 curl 测试

**注册用户**:
```bash
curl -X POST http://localhost:8080/api/user/register \
  -H "Content-Type: application/json" \
  -d '{"username":"13800138000","password":"123456","confirmPassword":"123456","nickname":"测试用户"}'
```

**用户登录**:
```bash
curl -X POST http://localhost:8080/api/user/login \
  -H "Content-Type: application/json" \
  -d '{"username":"13800138000","password":"123456"}'
```

**添加记账记录**:
```bash
curl -X POST http://localhost:8080/api/transaction \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer {your_token}" \
  -d '{"amount":100.50,"type":"EXPENSE","category":"餐饮","remark":"午餐"}'
```

**查询记账列表**:
```bash
curl "http://localhost:8080/api/transaction/list?pageNum=1&pageSize=10" \
  -H "Authorization: Bearer {your_token}"
```

**获取统计数据**:
```bash
curl "http://localhost:8080/api/transaction/statistics" \
  -H "Authorization: Bearer {your_token}"
```

## 九、技术栈

- **数据存储**: CSV 文件
- **安全**: JWT + SHA-256 密码加密
- **工具库**: Apache Commons CSV、Lombok
